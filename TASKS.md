# Tasks

Tasks for the Poop-Breakout project. Managed by `scripts/tasks.sh`.

Each task is a Markdown checkbox with inline tags.
Format: `- [ ] description \`priority:high|medium|low\` \`owner:name\` \`from:folder-or-source\``

Remove a task's `- [ ]` and replace with `- [x]` when done, or delete the line.
